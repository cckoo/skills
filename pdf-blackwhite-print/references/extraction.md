# 提取、识别与校核

## 逐页路由

预审报告是线索，最终结合截图。文字很多可能是错误的 OCR 层；满页图片可能只是背景，正文仍是有效矢量文字。

| 类型 | 处理 |
|---|---|
| 可靠原生文字 | 优先读取字体、字符坐标、方向、文本块和矢量；不重新 OCR 替换好文字。抽查选中复制、连字、数学符号、ToUnicode 乱码和单双栏顺序。 |
| 纯扫描 | 检查方向、裁边、倾斜、清晰度、阴影和透印；局部识别，保留每条文字和原坐标。低清小字需针对性放大，不把插值当新增细节。 |
| 扫描加 OCR 层 | 对照已有层和源图。可利用正确部分；错序、漏字、乱码或重复时重识相关区域，不叠加两层重复文字。 |
| 混合页 | 分区保留可靠文字，OCR 图片内文字；按几何去掉重叠识别项，再核对顺序。不要整本强制一种办法。 |
| 空白/异常 | 空白、纯封面、旋转、坏页、截断、密码、附件/批注内容分别记录。不能把提取失败当空白。 |

先按目录、分页、标题和栏结构建立顺序。两栏正文按栏读；表格按行列与合并关系读；树图按层级读；旁注、页眉、脚注独立处理。逐行按 y 坐标全页拼接会把表格、纵排标签和两栏互相穿插。

双页合扫先确认左右页序再分区；页旋转与图像方向分开核实。去倾斜、曲面展开、去阴影和透印应保留原图用于对照，不覆盖源文件。低分辨率、手写批注、装订遮挡、裁损或复杂公式需要局部复核；工具不支持或原图辨不清时列入待决，不能用语言模型猜补。裁边前保护页边注、印刷页码、表格外侧标签和页底最末行。原生文字不可提取而仍可见时，可对相应区域OCR，但要记录原因。

## OCR 选择与资源

- 优先使用环境中可用的本地中文 OCR、已授权的文档工具或 CLI；若需要外部服务，说明上传范围并遵守用户的本地/隐私限制。不擅自把全书传到新服务。
- 先用正文、彩色字、密表、脚注和罕见字做质量/速度小基准。Windows OCR 可作备选；不能假设系统 OCR 足以准确识别教材。
- 绿色字在普通灰度下可能过淡，可对照红通道/对比度版本；同引擎换通道只是辅助候选，不是独立校对。
- 复核可使用另一模型/引擎，最终仍由源图裁片裁决。第三模型也会改错人名、删否定词、给格线加数字。
- 下载模型应选可核实来源、记录版本/校验值，安装在任务环境。skill 本身不捆绑模型、不锁死历史版本或本机路径。
- 大书按页/区域存检查点和失败清单；输出原子落盘，崩溃可续跑。短批量比较 1/2/4 个工作进程的实际吞吐与内存，再限并发；逻辑 CPU 数不代表可用配额。单 agent 也可使用本地批处理，这不等于允许启动子 agent。

## 文本准确度

保留不可变原始记录，例如 `records:[{id,source_id,page_index,bbox,text,confidence}]`。稳定 ID 不随排版和更正改变。页号用一基物理页序，bbox 明确坐标单位、方向和缩放。

校订只改指定记录的完整文字，注明原字、新字、依据与状态。先精确应用更正，再结构化；不要多次对已校版本作全局字符串插入。脚注中的罕见字若每次执行都再加一个，重复执行就会悄悄产生多字。`apply_corrections.py` 拒绝冲突，且可重复应用同一份补丁。

必须对照的高风险内容：

- 人名、地名、专名、古字、异体字、诗句和引文。
- 年份、日期、百分数、数量级、单位、“万”、小数点、正负号。
- “不/无/未”等否定词、关键词缺一字、同形近形字。
- Ⅰ/Ⅱ 与 I/l/1/11，m′ 与 m、上下标、分式、希腊字母、公式合并单元格。
- 题号/考点号与后接数字标题粘连，如“考点90”后接“20世纪”不能显示成考点9020；装饰边缘也可能被识为 4.1、19 或多余括号。

平均置信度很高的长行也能漏一个关键字。完成一次候选校核后，对**已经发现的错形**全文回查，并用已核过的目录/树图节点反查标题。目录、图节点与正文可能原本用不同简称，不得为统一措辞擅自改书。

## 排除无用内容

区分三类：

1. 真正文：案例里出现“广告”“公众号”“二维码”、习题中的联系方式，并不自动是推广。
2. 页眉页脚导航：结合区域、方向、字号、反复出现与科目名判断；扫描下沉的页眉可能越过固定百分比阈值。不得截掉正文延续的半句话。
3. 独立推广/装饰：二维码、电话、外书封面、购买引流等可按用户要求去掉。明确记录范围和原因；如果课后面板只是让读者去另一本书练习，可在去无用内容范围内删，真实题目与脚注须单独保护。

只删已确认区域/记录，不用“页底统一裁切”或广告关键词全局删除。低位选项 C/D、图表来源、版权必要说明与脚注可能紧贴水印。

重复树图先检查是否是渐进展开、填空版、局部放大、续表或含独有节点。用户要求去重时，只删无新增信息的副本；不以同主题为由删正文的正常重复讲解。

原稿遮挡、缺页或疑字应如实记录。可以结合残形、上下文与序列作有依据的核校并标明；不能假装原字清晰，也不从外部常识补出书里没给的数值/句子。内容事实校正属于另一工作范围，用户没要求时以忠实提取为准。
